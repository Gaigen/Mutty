Mutty Architecture

Real-time voice collaboration platform — meety.smetrix.ru

Frontend Stack

  • • Web App (packages/web) — React 19 + Vite + TS
  • • Desktop App (packages/desktop) — Tauri v2
  • • Shared packages for types, utils, and UI primitives
  • • Tailwind CSS + shadcn/ui component system
  • • LiveKit React SDK for WebRTC media & data channels
  • • Theme system with light/dark mode support

Backend & AI

  • • Token Server — Node.js + livekit-server-sdk
  • • JWT token issuance (/api/token) with avatar validation
  • • Agent dispatch endpoint (/api/agent/dispatch)
  • • Agent Server — Python LiveKit Agent SDK
  • • OpenRouter LLM integration (GPT-4o-mini)
  • • youtube-bot voice agent participant

Infrastructure

  • • LiveKit Server — WebRTC SFU + data channels
  • • Docker Compose stack with healthchecks
  • • Coolify VPS deployment at meety.smetrix.ru
  • • pnpm workspace monorepo (web + desktop + shared)
  • • Stateless architecture — no persistent database
