pnpm monorepo — Real-time voice platform on LiveKit + Tauri

pnpm Monorepo

  • • packages/shared — 101 файл (компоненты, хуки, утилиты)
  • • packages/web — Vite + React, порт 1420
  • • packages/desktop — Tauri + Rust, порт 1421
  • • workspace:* зависимости, @shared/* алиасы

Backend & LiveKit

  • • Token Server — Node.js, выдаёт JWT для LiveKit
  • • Agent Server — Python, стримит YouTube/Twitch
  • • LiveKit — WebRTC SFU, аудио/видео/скриншаринг
  • • Docker Compose — 4 сервиса, healthchecks

Platform Abstraction

  • • StorageAdapter — localStorage (web) / Tauri Store
  • • ConfigAdapter — env vars (web) / dynamic URL
  • • NotificationAdapter — browser API / Tauri
  • • PlatformProvider + usePlatform() hook
